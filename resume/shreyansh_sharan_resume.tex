%------------------------------- Products --------------------------------------
\section{Product Built \textendash\ Omni Studio (Polestar Analytics)}
{\small\color{muted}An AI data platform on Databricks. I designed the architecture and built the
front end, back end and APIs. It is made up of five studios plus \textbf{Omni}, a page-aware
\faKeyboard\ \texttt{Ctrl+K} assistant available across the platform.}
\begin{itemize}
  \item \textbf{Foundation Studio:} an AI builder that reads client BRD and source-to-target mapping
        documents and drafts a governed \textbf{medallion model} (Bronze, Silver, Gold star schema with
        SCD2), its transformations and deterministic \textbf{Databricks SQL}. Each stage is approved by a
        person, then deployed through a 9-step onboarding wizard.
  \item \textbf{Governance Studio:} a control plane that scans Databricks jobs, clusters, SQL history and
        notebooks (12 collection targets) and covers column-level lineage, cost and LLM-spend budgets,
        right-sizing recommendations, access reviews and an immutable audit log.
  \item \textbf{ML Studio:} takes a business question to a deployed model: problem framing, a sandboxed
        guided notebook with \textbf{Optuna} tuning, \textbf{MLflow} experiments, champion models, deployment
        to Databricks serving, and drift monitoring.
  \item \textbf{Insights Studio:} a semantic layer (tables, knowledge graph, glossary, governed metrics and
        data-quality rules) with \textbf{AI-built dashboards}, ``ask why'' insights and natural-language-to-SQL
        over \textbf{Unity Catalog}.
  \item \textbf{Agent Studio:} agents with models, tools and \textbf{MCP} skills (one MCP server per studio),
        a live playground and full run traces, making the whole platform callable by agents.
\end{itemize}
